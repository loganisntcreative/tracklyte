# TrackLyte

> Free recruiting platform for high school track & field athletes and college coaches.

**[tracklyte.onrender.com](https://tracklyte.onrender.com)** — Public Beta

Athletes build a profile, log personal bests with race video, and get discovered by college coaches actively searching the platform. Coaches filter by event, graduation year, and state — then message athletes directly.

Built with Python/Flask · PostgreSQL · Tailwind CSS · Cloudinary · SendGrid
